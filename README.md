## Usage
- Every generator has a **preset menu** at the top of its panel (20–25 looks, grouped into Realistic, Stylized, Game-inspired and Sci-fi). Pick one or step through them with ‹ ›; applying a preset can be undone, and changing any setting turns it into custom settings. Generators define them as `presets: [{ name, group, values, aspect? }]`; a **Default** entry (the generator's own defaults) is added at the top of every list automatically.
- Effect textures that are usually tinted in the engine (muzzle flashes, cookie, lightning, light cone, particle) default to white / grayscale and all their presets are uncolored 1:1 textures. Their color fields are still there if you want to bake a tint in. Material and particle generators (grass, billboards, flashes, lightning, light cone) use 1:1 presets; only UI generators (UI border, shape buttons) keep wide presets.
- Generators carry up to 3 **tags** (Texturing, UI, Shooter, VFX, Lighting, Nature, Decals, Vehicles, Sci-fi). The filter bar above the generator grid (start page and the **+** picker) shows only the generators with the selected tag (one tag at a time; click it again or use **Reset filter** to show all). The filter is remembered. Generators define them as `tags: [...]`; the tag order lives in `U.TAGS` (core.js).
- Use **+** (or press `N`) to open a new generator tab. Double-click a tab name to rename it. Middle-click closes a tab.
- The preview renders at 256, 512 or 1024 px. Export goes from 256 up to 8K as PNG, WebP or JPG, or you can copy it to the clipboard.
- Undo / redo per tab: `Ctrl+Z`, `Ctrl+Y` / `Ctrl+Shift+Z` or the ↶ ↷ buttons (a whole slider drag is one step).
- **Aspect ratio:** pick a preset (1:1, 2:1, 16:9, …) or **Custom…** in the Aspect menu (top left) and type any width : height ratio (e.g. 3 : 1.25, sides 0.01–100); ⇄ swaps width and height. The export size sets the long side.
- Export sizes go down to 16×16; up to 128 px a **Hard pixels** toggle gives crisp pixel-art output, and the Preview menu can show the exact export size.
- **Normal map mode** (all Texturing generators except Grime / Grunge; a generator opts out with `normalMap: false`): the Texture / Normal map switch at the top of the panel (or `M`) shows a tangent-space normal map derived from the texture instead of the texture. The texture settings are replaced by a single **Normal** tab: strength, smoothing, Sobel or central-difference filter, height source (brightness, R, G, B, alpha), invert, height contrast, OpenGL / DirectX green channel and edge wrapping (on for tileable generators). Export and Copy then save the normal map (file name ends in `_normal`).
- **Tilesheet mode** (both muzzle flash generators): the Single frame / Tilesheet switch (or `M`) renders the flash forming and fading as a 2×2 up to 8×8 animation sheet, frames left to right, top to bottom. A **Tilesheet** settings tab sets the grid and the lifecycle (build-up, hold, start / end size, fade curve, dissipation, flicker, new noise per frame); the flash settings stay editable next to it. A player in the corner of the viewport loops the frames at the chosen FPS. The export size is the whole sheet (e.g. 2K at 4×4 = 512 px frames); the file name ends in `_sheet4x4`. Other generators can opt in with an `animate(params, frame)` hook (see `js/sheet.js`); with `animLoop: true` they get a seamless loop instead of the build-up / fade lifecycle (used by Insects & Spiders). A generator with both a normal map and an animation shows all three modes: Texture | Normal map | Tilesheet, and `M` cycles through them.
- Shortcuts: `T` toggles the 3×3 Tiling Preview, `R` picks a new seed, `M` toggles normal map / tilesheet mode, `F` fits the view, `1` shows actual preview pixels, `Ctrl+S` exports.
- **Languages:** English, Deutsch, Français, Español and Italiano, switched with the flags in the top right corner (the choice is remembered in localStorage). Everything is translated: interface, generator names and descriptions, every setting, tooltip and option, and all presets. Translations live in `js/i18n/<lang>.js` as `UGTG.addLang(code, { "English text": "Translation" })`; anything missing falls back to English, and code uses `UGTG.t("English text", ...args)` with `{0}` placeholders.
- Tabs and settings are saved in the browser's localStorage.
- `index.html#new=camo` (or another generator id) opens straight into a new tab.

## Adding a generator
Create `js/gen/<name>.js` that calls `UGTG.register({ id, name, desc, icon, params, render(ctx, W, H, p) })` and add a script tag for it to `index.html`. The settings panel is built automatically from `params`. Write sizes relative to `W`/`H` so the preview and every export size look the same.
